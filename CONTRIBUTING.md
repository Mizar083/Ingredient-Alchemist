# Feedback and Contributions

This public edition is a documentation and presentation hub, not the application source repository. Please keep reports clear, respectful, and free of private or sensitive information.

## Report a bug

Before opening a report, check whether the issue has already been reported. Use the repository's GitHub Issues page if issues are enabled. Include:

- What you expected to happen and what happened instead
- Steps to reproduce the problem
- The device, browser, and app area involved
- A screenshot or short recording when it helps explain the problem

Remove email addresses, account identifiers, recipe content you consider private, and other personal information from screenshots and reports.

## Questions and ideas

Use GitHub Discussions for general questions and feature ideas once Discussions are enabled for this repository. The expected Discussions URL is:

<https://github.com/Mizar083/Ingredient-Alchemist-Code/discussions>

This destination was not publicly accessible when this guide was prepared. Repository maintainers should enable Discussions and confirm the link before publishing this guide. Until then, contact [support@ingredientalchemist.com](mailto:support@ingredientalchemist.com) for general inquiries.

## Report a security issue

Do not post vulnerabilities, exploit instructions, credentials, or other security-sensitive information in a public issue or discussion. Send a private report to [support@ingredientalchemist.com](mailto:support@ingredientalchemist.com) with a concise description and steps to reproduce. Do not include real user data or secrets in the report.

## Changes to the project

For now, use issues or Discussions to report problems and suggest improvements. This documentation-only publication has no reuse license, and submitted patches or other material should not be assumed accepted for reuse. Maintainers should publish clear contribution and licensing terms before inviting pull requests.
